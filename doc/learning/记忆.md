### 框架结构（已落地）

```text
api-test/
├── conftest.py              # 全局 fixture + 后端检查 + ApiClient

├── common/                  # assertions, auth_helper, case_loader, http_client
├── api/                     # auth, category, product, inventory, cart, order
├── data/                    # accounts + data/json/*.json
├── tests/
│   ├── test_auth.py
│   ├── test_product.py
│   ├── test_cart.py
│   ├── test_inventory.py
│   ├── test_order.py
│   ├── test_chaining.py     # 第 7 课关联
│   └── test_smoke.py
├── pytest.ini
└── requirements.txt
```

### Pytest 关键能力（已会）

- `assert_api_success` / `assert_api_error`
- `admin_token` / `user_token` / `user02_token` fixture
- `admin_client` / `user_client`（ApiClient）
- `@pytest.mark.parametrize` + JSON 外置
- 接口关联：响应 `id` 传给下一步
- `pytest_sessionstart` 检查后端
- `-m smoke` 冒烟筛选

### 断言注意

- quantity≤0 → **90001**（参数校验），不是 50001
- 超库存减少 → **50002**
- 重复取消订单 → **40005**
