```text
├── tests/
│   ├── test_auth.py

│   ├── test_cart.py
│   ├── test_inventory.py
│   ├── test_order.py

│   └── test_smoke.py
├── pytest.ini
└── requirements.txt
```

### Pytest 关键能力（已会）

- `assert_api_success` / `assert_api_error`
- `admin_token` / `user_token` / `user02_token` fixture
- `admin_client` / `user_client`（ApiClient）
- `@pytest.mark.parametrize` + JSON 外置
- 接口关联：响应 `id` 传给下一步
- `pytest_sessionstart` 检查后端
- `-m smoke` 冒烟筛选

### 断言注意

- quantity≤0 → **90001**（参数校验），不是 50001
- 超库存减少 → **50002**
- 重复取消订单 → **40005**
