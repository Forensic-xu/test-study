## 4. 阶段 3 · Postman 明细

**工具**：Postman / Apifox（`pm.*` 脚本语法）  
**环境**：`mall-admin-test-local`

| 课时 | 主题 | 状态 |
|------|------|------|
| 01 | 登录 | ✅ |
| 02 | Token + Bearer 鉴权 | ✅ |
| 03 | Query / Path / 404 | ✅ |
| 04 | POST 创建分类 + 409/20006 | ✅ |
| 05 | PUT/DELETE + 20007 | ✅ |
| 06 | 库存增减 + 超库存 409 | ✅ |
| 07 | 购物车 + 403 隔离 | ✅ |
| 08 | 订单状态机 / 取消 / 支付 | 🔄 练习 1-5 ✅，剩余发货/完成/非法状态 |
| 09 | Collection Runner 串联 | ⬜ |
| 10 | 整理命名 + 导出备份 | ⬜ |

**集合结构**：

```text
01-Auth / 02-Users / 03-Categories / 04-Products
05-Inventory / 06-Cart / 07-Orders
```

**环境变量约定**：

| 变量 | 说明 |
|------|------|
| `base_url` | `http://127.0.0.1:8080` |
| `token` | 登录后 JWT；集合级 Bearer `{{token}}` |
| `category_id` | 推荐下划线命名 |
| `token_admin` / `token_user` | 多用户切换时用 |

**已踩坑**：

1. 创建分类误用 GET → 列表无 `data.id`
2. `category_id` vs `categoryId` 命名不一致 → 变量「没存上」
3. 订单：user01 下单/查看，admin 支付/发货/完成

## 8. AI 续课指令

当用户说「继续下一节课」时：

1. 读本文件 + `progress.md`
2. **默认续当前阶段未完课时**（Postman 08 剩余 → 09 → 10）
3. 若用户明确要学 Python/Pytest → **精简路线**：requests + 第一个 test_login，语法卡点再补
4. 带练风格：步骤短、期望表格、脚本可复制、做完让用户回报结果
5. 每完成一课：更新 `progress.md`、本文件「当前状态」、对应 lesson 检查清单
6. **不要擅自开** Selenium/JMeter/Jenkins，除非用户明确要求
7. Postman 用例可作为 Pytest 迁移素材，对照 `pytest-guide.md`
