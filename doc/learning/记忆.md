### 框架结构（已落地）

```text
api-test/
├── conftest.py              # 全局 fixture + 后端检查 + ApiClient
├── config/settings.py       # .env 支持
├── common/                  # assertions, auth_helper, case_loader, http_client
├── api/                     # auth, product, inventory, cart, order
├── data/                    # accounts, products, inventory_cases, cart, orders
├── tests/
│   ├── test_auth.py         # 5 条
│   ├── test_product.py      # 3 条
│   ├── test_cart.py         # 6 条
│   ├── test_inventory.py    # 7 条
│   ├── test_order.py        # 4 条
│   └── test_smoke.py        # 3 条（pytest -m smoke）
├── pytest.ini
└── requirements.txt
```

### Pytest 关键能力（已会）

- `assert_api_success` / `assert_api_error`
- `admin_token` / `user_token` / `user02_token` fixture
- `admin_client` / `user_client`（ApiClient）
- `@pytest.mark.parametrize` + `data/*.py` 外置
- `pytest_sessionstart` 检查后端
- `-m smoke` 冒烟筛选

### 断言注意

- quantity≤0 → **90001**（参数校验），不是 50001
- 超库存减少 → **50002**
- 重复取消订单 → **40005**
