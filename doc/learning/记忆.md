### 第 3～4 课最终方案（已验证通过）

**Pipeline 类型**：Pipeline script from SCM（方案 B，用户坚持不用粘贴脚本方案 A）  
**SCM**：Git，`file:///D:/code/test-study/.git`（本地仓库，GitHub 国内不稳定）  
**分支**：`*/main`（不是 master）  
**Script Path**：`mall-admin-test/api-test/Jenkinsfile`

**Jenkinsfile 完整内容**（仓库版，已验证）：

```groovy
pipeline {
    agent any

    // 定时触发：每 5 分钟自动跑一次
    triggers {
        cron('H/5 * * * *')
    }

    environment {
        CI_PYTHON = 'C:/Users/Administrator/AppData/Local/Programs/Python/Python312/python.exe'
    }

    stages {
        stage('API Test') {
            steps {
                dir('mall-admin-test/api-test') {
                    bat 'if exist ".venv1" rmdir /s /q ".venv1"'
                    bat '"%CI_PYTHON%" -m venv .venv1'
                    bat '.venv1\\Scripts\\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple --timeout 60'
                    bat '.venv1\\Scripts\\python.exe run.py report'
                }
            }
        }
        stage('Archive Report') {
            steps {
                archiveArtifacts artifacts: 'mall-admin-test/api-test/htmlreport/report.html', fingerprint: true
            }
        }
    }

    post {
        always {
            echo "=== 构建完成：${currentBuild.result} ==="
            echo "报告地址：${env.BUILD_URL}artifact/mall-admin-test/api-test/htmlreport/report.html"
        }
        success {
            echo '✅ SUCCESS — 全部用例通过！'
        }
        failure {
            echo '❌ FAILURE — 请检查控制台日志！'
        }
        unstable {
            echo '⚠️ UNSTABLE — 有用例失败但构建没挂'
        }
    }
}
```

### Jenkins 关键配置（永久生效）

**jenkins.xml 加 JVM 参数**（否则 file:// SCM 被安全拦截）：

```
-Dhudson.plugins.git.GitSCM.ALLOW_LOCAL_CHECKOUT=true
```

路径：`D:\Jenkins\jenkins\jenkins.xml` → `<arguments>` 标签里加

### cron 表达式图解（5 位）

```
H/5  *  *  *  *
 │    │  │  │  │
 │    │  │  │  └─ 星期几（0=周日, 6=周六, * = 每天）
 │    │  │  └─── 月份（* = 每月）
 │    │  └────── 日期（1-31, * = 每天）
 │    └───────── 小时（0-23, * = 每小时）
 └────────────── 分钟（H/5 = 每 5 分钟）
```
