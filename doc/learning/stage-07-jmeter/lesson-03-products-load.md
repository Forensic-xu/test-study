## 步骤 5：聚合报告怎么看（人话）

表格里每行是一个请求名（登录、商品列表），重点看这些列：

| 中文列名 | 人话 |
|----------|------|
| **标签** | 请求名称 |
| **样本** | 一共发了多少次 |
| **平均值** | 平均响应时间（毫秒），越小越好 |
| **中位数** | 一半请求比这个快 |
| **90% 百分位** | 90% 的请求不超过这个时间 |
| **最小值 / 最大值** | 最快、最慢 |
| **异常%** | 错误率，理想是 `0.00%` |
| **吞吐量** | 大概「每秒完成多少次」，越大通常越好 |

### 怎么判断「还行」？

入门标准很简单：

1. **异常% = 0**（没有红）
2. 把 5 用户和 10 用户的 **平均值**、**吞吐量** 记下来对比
3. 如果 10 用户时平均值明显变慢、或开始出现错误 → 说明压力上来了

把数字随手记在本子或下面表格：

| 并发 | 商品列表-平均值(ms) | 商品列表-异常% | 商品列表-吞吐量 |
|------|---------------------|----------------|-----------------|

| 10 |  |  |  |
