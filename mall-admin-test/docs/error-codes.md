# 错误码表（稳定约定）

> 本文件为测试断言依据。**已发布的错误码不要随意修改**。

统一响应体：

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

同时请断言 **HTTP Status** 与 body 中的 **code**。

## 成功

| code | HTTP | message |
|------|------|---------|
| 200 | 200 | success |

## 认证 / 用户（1xxxx）

| code | HTTP | message | 典型场景 |
|------|------|---------|----------|
| 10001 | 404 | 用户不存在 | 登录用户名不存在；查询不存在的用户 |
| 10002 | 401 | 密码错误 | 登录密码错误 |
| 10003 | 403 | 用户被禁用 | 使用 disabled 账号登录 |
| 10004 | 401 | Token 无效 | 伪造/篡改 Token |
| 10005 | 401 | Token 已过期 | 过期 JWT |
| 10006 | 401 | 未登录或缺少 Token | 未带 Authorization |
| 10007 | 409 | 用户名已存在 | 创建重复用户名 |
| 10008 | 403 | 无权限访问 | 普通用户访问管理接口 / 越权 |
| 10009 | 400 | 创建用户失败 | 创建用户落库失败 |

## 库存（5xxxx）

| code | HTTP | message |
|------|------|---------|
| 50001 | 400 | 库存调整数量非法 |
| 50002 | 409 | 库存不足，无法减少 |
